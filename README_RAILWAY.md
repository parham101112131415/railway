# راه‌اندازی روی Railway

## ۱) خیلی مهم — توکن‌ها رو عوض کن
توکن ربات و چندتا کلید API که توی فایل قدیمی‌ت بود، همین‌جا توی چت لو رفتن. قبل هر کاری:
- برو پیش @BotFather و با `/revoke` توکن قبلی رو باطل کن و توکن جدید بگیر.
- کلیدهای AudD / ACRCloud / Apify رو هم اگه امکانش هست عوض کن.

## ۲) چی عوض شد نسبت به نسخه VPS/ترموکس
- `bridge_config.py`: دیگه هیچ توکنی هاردکد نیست، همه از Environment Variables خونده می‌شه.
- `telegram_split.py`: این فایل توی زیپت اصلاً نبود (فقط import می‌شد) — از صفر نوشتمش. فایل‌های بزرگ‌تر از ۵۰ مگ رو خام (بدون افت کیفیت) به تکه‌های ۴۵ مگی می‌شکنه و پشت‌سرهم می‌فرسته؛ تکه آخر هرچقدر باشه همونو می‌فرسته. توضیح نحوه‌ی چسبوندن تکه‌ها هم توی کپشن تکه اول می‌ذاره.
- کوکی‌ها rename شدن به چیزی که `downloader.py` انتظارش رو داره: `youtube_cookie.txt` → `cookies.txt` و `instagram_cookie.txt` → `instagram_cookies.txt`.
- مسیرها (`BASE_DIR`, `DOWNLOAD_DIR`) به `/app` روی کانتینر اشاره می‌کنن، نه `/opt/bridge_bot`.
- بخش تونل داخلی xray (که فقط برای دور زدن فیلترینگ داخل ایرانه) دست‌نخورده مونده ولی اصلاً صدا زده نمی‌شه؛ چون Railway بیرون از ایرانه لازمش نداری.
- ماژول اختیاری «فیلم‌یاب» (`movie_bot`) توی زیپت نبود؛ کد خودش با try/except اگه پیداش نکنه فقط اون فیچر رو غیرفعال می‌کنه، بقیه ربات عادی کار می‌کنه. اگه اون پوشه رو هم داری بفرست تا اضافه‌ش کنم.
- فیچر تشخیص گوینده با `pyannote.audio` رو توی requirements نذاشتم چون کتابخونه‌ی سنگینیه (وابسته به PyTorch، حجم بیلد و ایمیج رو چند گیگ می‌بره بالا) و توی کد هم کاملاً اختیاریه. اگه لازمش داری بگو تا اضافه‌ش کنم.

## ۳) دیپلوی
1. یه ریپوی گیت‌هاب بساز و همه‌ی فایل‌های این پوشه رو توش push کن (یا مستقیم از Railway CLI دیپلوی کن).
2. توی Railway: New Project → Deploy from GitHub repo (یا `railway up` از همین پوشه).
3. Railway خودش `Dockerfile` رو می‌بینه و باهاش بیلد می‌کنه.
4. توی تب Variables این‌ها رو ست کن:
   - `BOT_TOKEN` (اجباری — توکن جدید از BotFather)
   - `OWNER_ID` (اختیاری — اگه می‌خوای آیدی‌های مجاز رو عوض کنی: `111,222`)
   - `AUDD_API_TOKEN`, `ACR_ACCESS_KEY`, `ACR_ACCESS_SECRET`, `APIFY_API_TOKEN`, `GROQ_API_KEY`, `YOUTUBE_DATA_API_KEY` (اختیاری — هرکدوم رو داری بذار، هرکدوم رو نذاری فقط همون فیچر خاموش می‌مونه)
5. دیپلوی کن. توی Logs باید ببینی: `ربات بریج دانلودر روشن شد...`

## ۴) نکته درباره دیسک
فضای دیسک روی Railway با هر ری‌دیپلوی پاک می‌شه (ephemeral). برای این ربات مشکلی نیست چون فایل‌ها دانلود می‌شن، تکه‌تکه به تلگرام فرستاده می‌شن و بعدش پاک می‌شن (`DELETE_AFTER_SEND=1`). فقط تاریخچه/کش (`history.json` و مشابه) با هر ری‌استارت از صفر شروع می‌شه؛ اگه می‌خوای اون‌ها هم بمونن، از Railway Volumes استفاده کن و `DOWNLOAD_DIR` رو به مسیر ولوم بده.
